# 질문의 핵심 대상과 발췌문 검증

2026-10-25 검색 개선.

## 원인

기존 검색 어휘는 조문 제목·정의·SOP 어휘를 중심으로 구성되어 법령 본문에만 있는 대상이 탈락할 수 있었다. 질문의 일부 단어만 연결된 경우, 넓은 주제를 언급한 조문도 검색 결과가 되었다. 호가 있는 항에서는 두 개 호만 선택해 임무 목록의 나머지가 빠지는 문제도 있었다.

## 처리

- 등록 원문 전체에서 질문에 실제로 쓰인 본문 대상어를 추가 식별한다. 문서 필터로 대상어가 사라지지 않도록 원문 어휘 확인과 검색 대상 필터를 분리한다.
- 조사·요청 표현과 기존 동의어를 처리한 뒤 남은 대상어를 필수 조건으로 유지한다. 새 대상어를 질문별 수동 사전에 추가하는 방식이 아니다.
- 법령은 선택한 항·호와 제목, SOP는 선택한 절의 발췌문에서 대상어를 다시 검증한다. 문서의 다른 부분에 단어가 있다는 이유만으로 통과시키지 않는다.
- 대상이 항의 도입부에 명시되고 호가 임무 등을 열거할 때에는 항과 전체 목록을 함께 유지한다.
- 연구위원은 법 제4조제5항·제6항으로 연결하며, 심의회에 부의한다는 고시·SOP 언급으로 대체하지 않는다.

## 검증과 한계

`tests/query-contract.test.mjs`는 실제 법령의 긍정 사례, 고시·SOP 필터의 오탐, 추가 조건 생략, 본문에만 존재하는 여러 대상어를 검사한다. 기존 검색·별표·SOP·갱신 검사 및 질문 감사도 배포 전에 실행한다.

이는 핵심 단어 누락과 부분 일치 오탐을 줄이는 제약이다. 임의 문장의 의미나 규정 간 법적 정합성을 완전히 이해하는 AI는 아니다. 미등록 동의어와 복합 조건은 검색 누락이 생길 수 있으며, 결과가 없다는 것이 규정 부존재를 뜻하지 않는다.
