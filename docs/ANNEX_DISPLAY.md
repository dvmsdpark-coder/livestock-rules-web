# 별표 본문 표시와 갱신

법령·고시·SOP의 별표는 문장은 텍스트로, 독립된 표는 행·열·병합 셀을 유지한 HTML 표로 표시합니다. 도안과 치수는 원문 이미지를 유지합니다. 쪽 경계에 걸친 표는 원래 세로선과 쪽 경계에서 끊긴 행을 복원하여 화면 표로 표시합니다. 문자 또는 셀 구조의 완전성을 확인할 수 없는 표는 펼쳐 보는 원문으로 보존합니다. 일반기준과 표가 혼재된 별표는 일반기준 문장을 먼저 읽을 수 있습니다. 같은 별표의 제목과 본문 전체 이미지를 반복해 노출하지 않습니다. 원문 이미지 대조 기능은 접힌 상태로 유지합니다.

`tools/build_annex_layouts.py`는 원문 PDF의 SHA-256을 확인하고 실제 별표의 모든 쪽을 검사합니다. 표를 텍스트로 옮길 때 각 문자의 수와 셀의 겹침·누락을 검사하며, 불일치 시 이미지로 보존합니다. 추출 자료는 `site/data/annex-layouts.json`에 생성되고 해당 PDF 해시와 일치할 때만 사용됩니다. 별지는 서식 배치를 유지합니다.

GitHub Pages 배포 과정에서 변환과 `tests/annex_layouts_test.py` 검사가 실행되므로 새 PDF 반영 시에도 같은 처리가 적용됩니다. 별도의 수동 별표 번호 목록으로 글 중심 별표를 지정할 필요가 없습니다. 치수·도안의 기존 검토 기록은 원문 해시에 한정되며 새 PDF로 무조건 이전되지 않습니다.

로컬 확인:

```powershell
node tools/list-annex-layouts.mjs
python tools/build_annex_layouts.py
python tests/annex_layouts_test.py
```

이 검사는 문자·셀 보존과 표시 분류를 확인하며 법령의 내용 또는 효력을 판단하지 않습니다. 표의 복잡한 구조가 불확실한 부분은 원문 확인이 필요합니다.

쪽 경계에서 이어지는 셀은 원문 위·아래 선의 열림, 열 위치, 병합 범위가 일치할 때만 연결합니다. 연결 전후 전체 문자와 셀 격자를 `node tools/verify_annex_layouts.mjs`로 다시 검사합니다. 같은 표의 전체 페이지 이미지는 기본 화면에서 반복하지 않습니다.

가로 구분선 없는 세부 항목은 번호·가)·나) 등의 원문 위치와 여러 금액 열의 기준선을 대조해 세부 행을 복원합니다. 공통 근거 셀은 병합을 유지하며, 항목과 수치가 같은 기준선에서 일치하지 않으면 순서만으로 배정하지 않습니다. 시행령 별표3 터목·퍼목의 항목별 1·2·3차 금액과 고목의 하위 가)·나) 금액은 별도 기대값 검사에 포함됩니다.

2026-10-26: 금액과 함께 경고·시정명령·업무정지·지정취소 등의 처분 열도 세부 행으로 정리합니다. 처분 문구가 여러 줄이거나 항목의 중간 높이에 배치되어 있어도 원문의 항목 범위에서 대응을 검증합니다. 새 항목 번호로 시작하는 다음 쪽은 이전 항목의 이어진 문장으로 합치지 않습니다.

고시·SOP에도 같은 변환과 검사를 적용하며, 반복 배경은 본문 도안과 구별합니다. 실제 수식·기호는 해당 셀을 원문에서 발췌해 보존합니다. 다음 별표가 새 쪽에서 시작하면 이전 별표 범위에서 제외하며, 본문 중 다른 규정의 별표를 인용한 문장은 새 별표 목차로 만들지 않습니다. 기존 유효한 목차 주소는 유지합니다.

점선으로 그어진 배점·평가기준 행은 짧은 선 조각도 먼저 보존한 뒤 연결해 추출합니다. 시행규칙 별표3의 평가항목 목록(4개 또는 2개)과 배점 단계(5단계 또는 3단계)는 다른 축으로 검증하며, 목록을 배점 단계와 임의로 대응시키지 않습니다. 기준·점수 21개 대응과 공통 목록 병합을 회귀 검사에 포함합니다.

본문과 표 셀의 번호 표시는 원문 문자를 바꾸지 않고 경계만 나누어 표시합니다. `가.`, `1)`, `가)`, `(1)` 등의 하위 단계는 동일 깊이에서 정렬하고 쪽이 바뀌어도 이어집니다. 표 안에서 `(가)`의 하위 항목이 `1)`로 시작하는 경우에는 셀 내부의 단계로 처리합니다. 날짜·치수·괄호 인용과 이미 연결된 조문 링크는 항목 번호로 쪼개지 않습니다.

별표의 중복 제목 앞에 추출된 책 쪽 번호는 해당 제목과의 일치가 확인될 때만 화면 본문에서 제외합니다. 예: HPAI SOP PDF195쪽의 책 쪽 번호188. 원본 PDF와 추출 원문은 보존하며 화면의 PDF 쪽 링크는 실제 PDF 쪽을 표시합니다. 이 조건은 새 PDF에도 적용하며, 일반 본문의 독립 숫자를 일괄 삭제하지 않습니다.

SOP의 책 쪽 번호는 제목 앞에 있는 경우뿐 아니라 페이지가 바뀌는 중간 위치에서도 제외합니다. PDF 상단·하단 여백 또는 회전된 서식의 좌우 여백에서 추출된 숫자가 같은 위치와 페이지 번호 흐름으로 3쪽 이상 반복되고, 원본 추출문의 첫 줄 또는 마지막 줄과 일치할 때만 표시용 쪽 번호로 지정합니다. 화면에서는 주변 본문까지 일치하는 경우에만 같은 길이의 공백으로 처리하여 조문 링크 위치를 유지합니다. 표 셀의 숫자에는 이 처리를 적용하지 않습니다. PDF217쪽의 책 쪽 번호210 및 본문의 14일 등 수치를 회귀 검사합니다. 판별 정보는 PDF 해시에 연결되어 새 PDF 등록·배포 시 다시 계산합니다.

법 조문의 ①·② 항과 별표·SOP의 ①·② 세부 목록은 문맥을 구분합니다. 별표의 `2) → ※ → ①~④`는 주석 아래 목록으로 정렬하고, 다음 `3)`는 기존 `2)`와 같은 단계로 돌아갑니다. 같은 주석의 항목이 다음 쪽에 이어져도 깊이를 유지합니다. 법령 본문의 항 번호는 기존 조문 구조를 유지합니다.

글 중심 별표도 PDF의 문자 좌표에서 복원한 줄·띄어쓰기를 생성 자료에 저장하고, 화면에서 그 자료를 우선 사용합니다. 원문 PDF의 비공백 문자 수와 일치해야 하며, 불일치한 페이지는 원문 배치를 보존합니다. 전체 본문과 선택 발췌를 구분하여 발췌에 전체 쪽이 섞이지 않도록 합니다. 이 자료에서는 줄 시작의 번호만 실제 항목으로 보고, 문장 중의 `아래 가)·나)·다)` 인용은 문장 안에 유지합니다. 소득안정비용 지원요령 별표1의 PDF5~9쪽과 산출식 기호·3%·10일 기준을 회귀 검사합니다.

보상금 고시의 별표1의2·별표2·별표3은 숫자 제목 아래 `□ → ○ → -` 기호의 단계와 형제 항목 복귀를 구분합니다. `※` 기준 설명과 별표 표 아래의 `*` 주석을 별도 행으로 표시하며, 다음 쪽의 설명도 같은 상위 항목 안에 유지합니다. 혼합 별표의 표 밖 문장에도 PDF 원문 줄 배치를 적용하고, 관련 조문이 붙은 중복 제목은 제목임을 확인한 경우에만 본문에서 제외합니다. 글꼴 크기가 달라도 항목 깊이의 간격은 동일하게 유지합니다.

별표2의 번호 없는 축종별 지급액 목록은 PDF의 구분명과 금액이 모두 같은 기준선에 있는 경우에만 세부 행으로 나눕니다. 축종과 한 번만 적힌 공통 비고는 병합을 유지하며, 반복된 같은 비고가 서로 다른 금액 줄에 대응할 때만 해당 줄로 나눕니다. 젖소 5개·한우 3개·돼지 2개 구분과 금액을 별도로 회귀 검사합니다.

반복 비고가 원문의 금액 기준선과 정확히 대응하지 않으면 세부 행에 임의 배정하지 않습니다. 병합 셀을 유지하고, 같은 비고가 여러 번 적힌 경우에는 원래 줄바꿈을 보존해 구분합니다.

문장 끝 `한\n다. 방문자는`처럼 줄이 바뀐 종결어미는 글자 모양만으로 새 목으로 보지 않습니다. PDF의 실제 목 기호보다 안쪽의 연속 본문 위치에 있고, 앞뒤 목이 같은 위치에서 순서대로 이어지며, 행간도 같은 문단임이 확인될 때만 줄바꿈을 연결합니다. 같은 위치의 실제 다목이나 불확실한 경우는 바꾸지 않습니다. 시행규칙 별표2의4 PDF95쪽의 실제 다목 두 개를 유지하면서 `한다. 방문자는`을 복원하는 검사를 포함합니다.

한 행에 여러 목이 있는 병렬 배열은 PDF 문자 좌표에서 열 간격이 충분히 크고, 두 행 이상에서 열 위치와 목 순서가 일치할 때만 각각의 행으로 풀어 표시합니다. 단순한 문장 안 인용, 한 행뿐인 경우, 순서나 열 위치가 불일치하는 경우는 나누지 않습니다. 시행규칙 별표14의5 제4호의 8개 통보 항목을 원래 순서대로 유지하는 검사를 포함합니다.
