규정 문서 갱신 관리

새 PDF를 후보본으로 준비하고, 달라진 원문과 검색 결과를 검토한 뒤 공개 자료에 반영합니다.

이 화면은 이 PC에서만 실행됩니다. PDF는 외부 AI로 전송하지 않습니다. 공개 GitHub Pages에는 관리 화면이 배포되지 않습니다.

등록 문서를 불러오는 중입니다.

1. 새 PDF 준비

같은 파일·같은 버전·같은 기준일은 공개본을 바꾸지 않는 재현 검사로 처리합니다. 새 개정판의 기준일은 이전 버전보다 뒤여야 합니다.

2. 원문 변경과 경계 검토

기존 PDF · 새 PDF

고급 설정 원문(JSON)

자동 추출은 초안입니다. 별표·별지의 시작·끝 페이지, 그림/서식/간지 분류, SOP의 참고자료 제외 범위와 절차를 원문과 대조하세요. 이전 PDF의 페이지 범위는 새 파일에 자동 재사용하지 않습니다.

page_kinds: body(본문), table(표), form(서식), figure(그림), blank(공백), title(간지). exclude: [[시작,끝]]. procedures: intent(reporting / movement_release / farm_disinfection), start, end, anchor(시작 페이지의 실제 제목), heading, scenario.

3. 검사 결과와 질문 영향

검사를 실행해주세요.
추가·변경·삭제된 조문

번호가 바뀐 조문은 후보로만 안내합니다. 변경된 번호나 조건을 자동으로 정답이라고 확정하지 않습니다. 실패 항목이 있으면 공개 반영이 차단됩니다.

4. 검토 완료 후 로컬 공개본 반영

반영은 이 PC의 공개용 폴더를 갱신합니다. 인터넷 공개는 GitHub에 변경 파일을 올리고 자동 배포 검사가 통과한 뒤 이루어집니다. 이전 PDF·색인과 적용 기간은 보존합니다.
