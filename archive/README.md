# 보관: 질문 검색 화면

2026-10-25부터 공개 서비스는 규정 열람과 본문 키워드 검색에 집중합니다.

기존 화면은 `question-search.html`에 보관합니다. 검색 엔진과 회귀 테스트도 유지하며, 공개 메뉴에서는 연결하지 않습니다. `site/search.html`은 기존 주소를 방문한 사용자를 규정 열람으로 이동시킵니다. 이전 조문 링크의 문서·조문·기준일은 열람 주소로 변환합니다.

복구를 검토할 경우 보관 HTML을 `site/search.html`로 복사하고 메뉴를 다시 연결할 수 있습니다. 정확성 검증 후 공개 여부를 결정합니다. 보관 폴더는 GitHub Pages 배포 대상인 `site` 밖에 있습니다.
